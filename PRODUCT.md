# MCVoice product context

## Register

product

## Users

Minecraft Java players using proximity voice and optional voice groups while playing.

## Product Purpose

Provide voice chat without a Minecraft server plugin, with a configurable HUD that
communicates voice activity without interrupting play.

## Brand Personality

Familiar, compact, practical. Settings follow Minecraft's vanilla controls and font.

## Anti-references

Avoid web dashboard styling, decorative animation, and copying Simple Voice Chat
code or assets. Use the user's reference only as a guide to roster behavior.

## Design Principles

* Keep gameplay visible and show voice state at a glance.
* Use the existing Minecraft drawing and settings components.
* Keep HUD elements independently adjustable across GUI scales.
* Preserve Java 8 core compatibility and validate platform API differences.

## Accessibility & Inclusion

Use readable shadowed names and a white speaking outline so activity is not
communicated by color alone. Provide visibility toggles and adjustable HUD size.
