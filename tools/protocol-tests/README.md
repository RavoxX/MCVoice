# Protocol conformance

`run.sh` proves that the Java client, the Rust backend and the Go backend
speak the same wire protocol and behave identically:

| layer | how |
|---|---|
| byte-exact wire format | `protocol/test-vectors/*.json`, generated by an independent Python reference (`generate.py`), verified by Go (`internal/protocol`), Rust (`tests/vectors.rs`) and Java (`client/network`) |
| routing decisions | `routing.json` evaluated by the Go and Rust routing functions |
| client playback + dedup | `playback.json`, `dedup.json` evaluated by the Java client |
| black-box behaviour | `backend/go/pkg/conformance` scenarios (30) run against both backend binaries |
| full stack | `client/core` end-to-end tests (two/three headless clients) against both backend binaries |

CI runs the same steps (`.github/workflows/ci.yml`).
